🍰 How to Make a Recipe Website

Click the links as you go — this page will style itself as you learn.

You have recipes you love and want a little website for them. Right now this page is completely unstyled — it looks like the plain internet of 1995. By the end, it'll look lovely.

What is the first thing you need?

1. Write your recipe

A website is just a text file. Open Notepad (or TextEdit), type this, and save it as index.html:

<h1>Banana Bread</h1>
<p>Moist, simple and always disappears fast.</p>

<h2>Ingredients</h2>
<ul class="ingredients">
  <li>3 ripe bananas</li>
  <li>200g sugar</li>
  <li>250g flour</li>
</ul>

<h2>Method</h2>
<p>Mash the bananas, mix everything, bake at 180°C for 50 minutes.</p>

Double-click the file and it opens in your browser. Looks plain, right? Time to add a second file called style.css. What is the first rule to write?

2. Centre the text

Lines of text stretching across a huge screen are tiring to read. Keep them in a neat column in the middle:

body {
  margin: 0 auto;
  max-width: 40em;
}

See how this page just shrank into a column? Next, the lettering.

3. Pick a font

The default font looks a bit dated. Georgia is a warm, friendly choice for recipes. (Helvetica is a cleaner, modern one.)

body {
  font-family: Georgia, serif;
}

Now let's give everything some breathing room.

4. Add space

If a page looks "squashed" or "broken", it's nearly always missing space. Add space between lines, and around the edges:

body {
  line-height: 1.6;
  padding: 2em 1em 4em;
}

h2 {
  margin-top: 1em;
  padding-top: 1em;
}

Much better. Now some gentle colour.

5. Soften the colours

Pure black on white is harsh. Use a soft grey for the text, and a slightly darker grey for headings so they stand out:

body {
  color: #555;
}

h1, h2, strong {
  color: #333;
}

Recipes need an obvious ingredients list — let's make a special box for it.

6. Ingredients box

Remember the class="ingredients" we added to the list? Now we can style just that list:

  • 3 ripe bananas
  • 200g sugar
  • 250g flour
.ingredients {
  background: #fdf6e3;
  border-left: 4px solid #e0b252;
  padding: 1em 1em 1em 2.5em;
}

Now let's give your site its own signature colour.

7. Choose your signature colour

Most brands have one colour that ties everything together. Pick one you love (we've gone for a warm tomato red) and use it for links and headings:

a {
  color: #d9534f;
}

h2 {
  color: #d9534f;
  border-bottom: 2px solid #f3d3d1;
}

Finally, make the top of the page stand out.

8. A proper header

Wrap your title in a <header> tag in your HTML, then colour it. Scroll up to see the change!

header {
  background: #d9534f;
  border-radius: 12px;
  text-align: center;
  padding: 2em 1em;
}

header h1 {
  color: white;
  font-weight: 400;
}

Tip: add a mouth-watering photo of your food as a background-image later. There's just one last thing.

9. Put it online

Your website is finished! To share it, you need to publish it. The easiest free way:

  1. Make sure index.html and style.css are in one folder.
  2. Go to netlify.com/drop.
  3. Drag your folder onto the page.
  4. You get a link you can send to the family.

Don't forget to link your CSS by adding this line inside <head> of your HTML:

<link rel="stylesheet" href="style.css">

Well done! 🎉
